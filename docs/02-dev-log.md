### 第 10 轮的测量口径

RSS 不是泄漏判据：Chrome 分配器会保留高水位，全部移除图片后渲染进程 RSS 仍约 490MB，但应用持有的画布字节与 DOM 中的 canvas 元素均为 0，触发内存压力也只回落约 9MB。因此以「应用持有字节数」为准，诊断入口在开发态由 `window.__tfCache()` 暴露（底图 / 预览 / 统计 / 历史栈）。

## 验证方式

- **桌面构建**：`npm run build` → `npx tauri build` → `npm run check:bundle`。
- **冒烟**：`TF_SMOKE=1 <app>/Contents/MacOS/qingying` 启动打包后的二进制，依次导入合成图、调色、水印、导出 PNG/JPG，stdout 输出 `[smoke] PASS`。
- **回归脚本**：Playwright-core 驱动本地 dev server，读取 `window.__tfCache()` 与导出产物的像素统计。

## 已知限制

- 锐化/降噪为固定 3×3 半径，柔化为固定比例半径；缩小预览的锐度观感强于 1:1。
- 不支持 RAW、HDR、ICC 嵌入；导出为 sRGB。
- 自动调色仅做全局处理，不做人脸/天空分割。
- 裁剪框与曲线画布仍是鼠标/触屏专用，色阶提供数值输入作为键盘替代。
- 仅本地运行，无账号、无云端。
